# kola-management-event
The project is build entirely with java technologies
the frontend (user and admin views) and the backend fonctionnalities.

For the backend we use Spring boot framework v3.4.4 java 21
For the frontend we use Thymeleaf
    
The application start on port 8081

- User Registration
  -
      use "/" and /register

- Admin Registration
  -
      use "/admin" and /admin/register


- Launching the application 
  -
    gradlew build && gradlew boot:application run
   at the root of the project
